# AutoMooc

超星学习通自动刷课脚本，自动播放视频、跳过已完成/非视频章节。

## 使用方法

### Tampermonkey（推荐）
安装 `autoMooc.user.js`，脚本会在 `mooc1.chaoxing.com` 的视频课程页面自动运行。

### 浏览器控制台
打开视频课程页面，F12 打开控制台，贴入 `autoMooc.js` 全部代码后回车。

## 功能

- 自动查找页面及 iframe 中的视频并播放
- 视频结束后自动跳转下一章节
- 自动跳过 PPT、测试、测验、作业等非视频章节
- 检测并跳过已完成的章节
- 第一轮完成后全量重扫描，确保无遗漏
- 倍速播放（0.75x / 1x / 1.25x / 1.5x / 2x）
- 从头播放 / 拖到底两种模式
- 卡顿检测（30 秒无进度自动刷新）
- 自动续播（检测暂停自动恢复）
- 右上角控制面板，所有功能可开关
